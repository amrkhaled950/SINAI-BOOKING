# Sinai Booking (سيناء بوكينج)

> **"We are The old school of tourism"**
> Find your kind of escape — Dahab accommodations, South Sinai desert safaris & jeep tours, private & group transfers, and authentic field notes.

---

## 🌴 Overview

**Sinai Booking** is a bespoke, high-performance web platform crafted for travellers seeking authentic experiences in Dahab, Taba, Nuweiba, and South Sinai. Built with **React 18**, **Vite**, and **Tailwind CSS**.

### Key Features:
- 🏖️ **Dahab Accommodations**: Pixel-perfect showcase featuring the Mashraba Duplex (Studio 1) and upcoming Dahab apartments.
- 🛏️ **Room Details & Booking**: 8-photo interactive gallery, lightbox, dates/stay calculator (daily & monthly stay), and direct WhatsApp booking.
- 🚙 **Desert Safaris & Jeep Tours (Excursions)**:
  - Arada Canyon Day Trip
  - Sandboarding Day Trip (Hedoda Sand Dune)
  - Overnight Desert Trip (2 Days / 1 Night)
  - Camp Options: *The Romantic Camp (Zigzag Canyon)* and *The Stargazer's Camp (Gebel Makhroum)*
  - Full itineraries, schedules, inclusions, and essentials.
- 🚐 **Transportation & Transfers**: Hiace buses for small groups/families, and private car transfers between Sharm El Sheikh, Dahab, and Taba/Nuweiba.
- 📖 **Field Notes & Blog**: Curated stories, local secrets, and travel tips with full interactive reader drawer.
- 💬 **Direct WhatsApp Integration**: Pre-formatted booking messages sent directly to `+20 111 666 4591`.
- 🌐 **Full Bilingual Support**: Instant switching between English (LTR) and Arabic (RTL) with native typography.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel ready (`vercel.json`)

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/<your-username>/SINAI-BOOKING.git

# Enter project directory
cd SINAI-BOOKING

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build & Deployment

```bash
# Build production bundle
npm run build
```

Ready for one-click deployment on **[Vercel](https://vercel.com)**.
